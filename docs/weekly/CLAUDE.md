# docs/weekly

주간 롤업·회고 보관소다. daily 로그와 세션 산출을 주 단위로 압축 요약해 둔다.

## 무엇을 넣나
- `SKILL-HARVEST-YYYY-MM-DD.md` — 세션에서 자산화한 스킬/패턴 수확 회고.
- `YYYY-MM-DD-rollup.md` — 해당 주의 daily(`docs/daily/`)를 압축한 요약.

## 규칙
- **현재 상태 사실은 여기 두지 않는다.** 그건 `docs/status/PROJECT-STATUS.md`에만.
- 진입 문서(`PROJECT-STATUS.md`)에는 여기로의 링크 1줄만 남긴다(중복 서술 금지).
- 파일은 최상단 1~5줄 헤더 주석으로 무엇/언제를 표기.
