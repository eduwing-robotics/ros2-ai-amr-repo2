① 두 로봇을 같은 통신망으로

로봇·컴퓨터가 서로 신호를 주고받게 채널을 하나로 맞췄어요

⚠️ 힘들었던 점

  • 젠지 로봇이 와이파이로 안 잡힘(랜선과 와이파이를 동시에 꽂아 신호가 엉킴)
  • 로봇마다 통신 채널 번호가 달라서 서로 못 봄
  • 팀 와이파이가 가끔 끊겨서 시연이 불안

✅ 어떻게 풀었나

  • 랜선을 빼고 와이파이 하나로만 연결
  • 로봇·컴퓨터 채널 번호를 똑같이(210) 맞춤
  • 서로 잘 보이고 카메라·센서도 잘 들어옴

② 센서 4종을 한 보드에

사람 감지 · 레이저 · 소리 · 온도 센서를 하나의 작은 보드에 붙였어요

⚠️ 힘들었던 점

  • 레이저를 엉뚱한 자리에 꽂아 보드에 프로그램이 안 올라감

✅ 어떻게 풀었나

  • 센서마다 꽂는 자리를 정리해서 다시 연결
  • 소리는 소리 크기 변화로 직접 감지하게 바꿈
  • 온도는 다른 부품으로 교체해서 값이 나오게 함

③ 화면 기록을 자동 저장

화면에서 누른 일·출동 좌표·로봇 위치를 클라우드 저장소에 자동으로 남겨요

⚠️ 힘들었던 점

  • 저장소가 안 쓰면 자동으로 잠들어 접속이 막힘
  • 저장 방식을 복잡한 것 vs 간단한 것 중 골라야 함
  • 화면 편집기가 변경을 바로 반영 안 함

✅ 어떻게 풀었나

  • 가벼운 방식 선택(끊겨도 모았다가 다시 보냄)
  • 저장소를 다시 깨우고 접근 권한 설정
  • 편집기 창을 띄워주면 바로 반영 → 저장 성공

⑤ 방 지도 새로 그리고 로봇 표시
