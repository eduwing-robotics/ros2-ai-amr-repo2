주요 기술

Admin PC

관리자 관제 화면 (Unity Control Room)

Unity, ROS-TCP

Main Server

AI 분석, 이벤트 파이프라인, DB 저장

FastAPI, YOLO, PostgreSQL

T1 (순찰로봇)

RealSense RGB·Depth 전송, 순찰 경로 이동

ROS2, Nav2, RealSense D435

Gen.G (출동로봇)

현장 출동, PIR·온도·레이저·Pi Camera 재확인, 워터 펌프 제어

ROS2, Pi Camera v2, Arduino Nano/Uno (USB 시리얼), 릴레이·워터 펌프

데이터 흐름 요약

  1. T1이 RealSense RGB/Depth 영상을 Main Server로 전송

  2. Main Server가 YOLO 분석 후 이벤트 생성 → Unity에 경고 표시

  3. 필요 시 Main Server가 Gen.G에 출동 명령 전송

  4. Gen.G가 PIR·온도·레이저 센서 + Pi Camera로 현장 재확인 후 결과를 Main Server로 전송. 화재 EVACUATE 확정 시 워터 펌프 분사 명령 실행.

  5. 관리자 판단 결과와 영상·위치 정보를 DB에 저장
