목적

박물관 및 미술관 보안을 위한 순찰 로봇과 관제 시스템의 요구사항을 쉽게 이해할 수 있도록 정리한 문서이다.

우선순위

SR_01

자동 순찰

로봇이 미리 정해진 경로를 따라 반복 순찰한다.

  • 자동이동수행

  • 장애물 감지

  • 장애물 회피

R

SR_02

자동 충전

로봇이 순찰 도중 배터리가 30%이하일 경우 지정된 충전 장소로 이동한다.

R

SR_03

출동 요청

로봇이 순찰중 이상 상황을 감지시 메인 서버에 출동을 요청한다.

  • 이상 위치를 메인 서버에 전송

  • 대기중인 Gen.G로봇을 이상 위치에 출동

R

SR_04

데이터 전송

순찰하는 로봇의 데이터를 메인 서버에 전송한다.

  • 센서 정보

  • 로봇 상태

    • 배터리

    • 로봇 정보 (이름, 펌웨어 버전 등)

  • 동작 로그

    • 카메라

    • 동작 상태 (순찰중, 스캔중, 충전중, 현상 처리 중)

R

SR_05

카메라

로봇에 부착된 카메라로 이상을 감지한다.

  • Depth 카메라로 환경을 인지

  • RGB 카메라로 현상을 촬영

R

SR_06

외부자 감지

PIR 센서로 외부자가 있는지 감지한다.

  • 데이터 전송

  • 출동 요청

  • 차단벽 닫힘 요청

R

SR_07

외부자 조치

외부자를 조치한다.

  • 전기 총

  • 물리 공격

O

SR_08

소음 감지

일정 데시벨 이상의 소음 발생을 감지한다.

  • 데이터 전송

  • 출동 요청

  • 알림 표시

R

SR_09

화재 감지

온도 센서, 카메라를 사용해 화재를 감지한다.

  • 데이터 전송

  • 출동 요청

  • 알림 표시

  • (Opt)워터 펌프를 활용해 화재 진압

  • (Opt) 119 알림 — 시연용 UI 알림만 발생, 실제 신고 호출 없음

R

SR_10

관리 화면

로봇이 전송하는 데이터를 바탕으로 현장의 상태들을 관리한다.

  • 로봇 상태 뷰

    • 현재 위치

    • 이동 경로

    • 배터리

    • 카메라

  • 센서 정보 뷰

    • 레이저 ON/OFF

    • 데시벨

    • 온도

    • PIR

  • 로그 뷰

  • 로봇 수동 조작

  • 알림 및 신고 처리

  • DB 저장

  • 로봇 작업 할당

R

SR_11

DB

  • 날짜 별 폴더 생성

  • 검색

  • 이미지

  • 영상

  • 로그

    • 시간

    • 로봇 상태

    • 동작

    • 신고 내역
