🎯 MVP 한 줄

티원이이 박물관/미술관 전시 구역을 순찰하며 액자형 사진 타깃과 센서 이벤트를 감지하면 Unity 관제 화면에 위치·이벤트가 표시되고, 젠지가 감지 지점으로 출동해 카메라·센서·워터 펌프로 현장을 확인·대응하며, 모든 이벤트와 대응 결과를 DB에 기록한다.

❓ 왜 만들까?

기존 자율주행 데모는 로봇 이동 자체만 보여주기 쉽다. 이 프로젝트는 박물관/미술관 경비 상황을 가정해 티원이 이상을 감지하고, 젠지가 출동/확인하며, Unity 관제실이 모든 상태를 실시간으로 보여주는 분업 협력 구조를 만든다.

  1. 상황 감지 — PIR·소리·온도·레이저 모듈·Pi Camera·LiDAR로 외부자/소음/화재 의심 상황을 감지한다.

  2. 보호 대상 확인 — 액자형 사진 타깃 또는 중요물품을 카메라 확인 대상으로 둔다.

  3. 협동 대응 — 한 로봇이 감지하면 다른 로봇이 확인 위치로 이동하고, 화재 확인 시 워터 펌프로 모의 대응한다.

  4. 관제 시각화 — Unity에서 로봇 위치, 상태, 이벤트 마커, 카메라 라이브 스트림, 출동 흐름을 보여준다.

  5. 기록과 분석 — DB 4테이블에 이벤트/출동/카메라 확인을 저장하고, 추후 좌표·미디어·보호대상 저장으로 확장한다.
