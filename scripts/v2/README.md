# nav2_goal — grid 좌표로 로봇 보내기 (Nav2 주행)

grid(0~200) 좌표를 주면, 로봇이 그 지점으로 **Nav2로 알아서 경로를 찾아** 이동합니다.
장애물이 있으면 Nav2가 우회하고, 낀 상황(스턱)이면 스스로 빠져나오려 시도합니다.

## 어떤 파일을 쓰나

| 파일 | 언제 |
|---|---|
| **`nav2_goal_v4.py`** | **추천.** 맵 파일(`--map`)에서 좌표계를 읽음 → 맵 바뀌어도 코드 수정 X |
| `nav2_goal_v3.py` | 좌표계가 코드에 하드코딩된 버전 (맵이 고정일 때) |

기능은 같고, **좌표계를 파일에서 읽느냐(v4) / 코드에 박느냐(v3)** 만 다릅니다.

## 먼저 준비 (전제)

1. **Nav2 실행 중**이어야 함
2. **로봇 위치가 잡혀 있어야 함** — RViz에서 `2D Pose Estimate`로 초기 위치 지정 (AMCL localize)
   - 안 되어 있으면 스크립트가 "localize 안 됨 → 주행 중단"으로 안전하게 멈춤

## 실행 방법

```bash
# v4 — 맵 파일 주고 grid(100,100)로 이동
python3 nav2_goal_v4.py --map ~/urhynix/waypoint/map5.yaml 100 100

# 여러 점 순찰 + 반복
python3 nav2_goal_v4.py --map map5.yaml 50 50 150 150 --loop

# v3 — 좌표만 (맵 하드코딩)
python3 nav2_goal_v3.py 100 100

# 옵션 전체 보기
python3 nav2_goal_v4.py --help
```

## 자주 쓰는 옵션

| 옵션 | 뜻 | 기본 |
|---|---|---|
| `--map <map.yaml>` | 좌표계를 맵 파일에서 읽음 (v4만) | — |
| `--loop` | 경로 계속 반복 (Ctrl+C까지) | 꺼짐 |
| `--laps N` | N바퀴만 돌고 종료 | 0(무한) |
| `--timeout 초` | 한 구간 제한시간 | 90 |
| `--stuck-time 초` | 이만큼 진전 없으면 "스턱"으로 판단 | 15 |
| `--max-escape N` | 스턱 시 탈출 시도 횟수 | 4 |

## 똑똑하게 처리하는 것들

- **장애물 회피** — Nav2가 우회 경로를 찾음
- **스턱 탈출** — 낀 걸 감지하면 뒤로 빠졌다 옆으로 비껴 다시 시도.
  `/scan`으로 **트인 쪽부터** 시도하고, 막히면 반대쪽으로 번갈아
- **못 가면 건너뜀** — 몇 번 시도해도 안 되면 그 점은 스킵하고 다음으로 → **순찰이 안 죽음**
- **갈 수 없는 목표 사전 차단** — 벽 속 같은 목표는 미리 걸러 헛수고 안 함
- **안전 정지** — Ctrl+C로 끊으면 로봇도 멈춤

## 참고

- 좌표는 **grid 0~200** 범위. 실제 map 미터 좌표로는 스크립트가 자동 변환.
- 로봇은 TurtleBot3 Burger. **후방 라이다가 없어** 탈출 시 후진은 뒤가 트인 곳에서만 안전.
