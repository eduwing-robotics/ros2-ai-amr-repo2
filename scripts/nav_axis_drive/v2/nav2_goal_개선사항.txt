■ 버전 계보 (기능 누적)
----------------------------------------------------------------------
 nav2_goal.py       베이스라인
                    - grid(0~200) 목표 -> BasicNavigator.goToPose
                    - 피드백 로그(남은거리/ETA/경과/복구횟수)
                    - 다중 웨이포인트 + --loop, 도착방향 정책
                    - Nav2 대기 60초 로그, 안전종료 + 중단 시 goal 취소

 nav2_goal_v3.py    v3 = 베이스라인 + 견고성/UX (좌표계는 하드코딩)
                    - 스턱 감지(무진전 + 복구 임계)
                    - 번갈이 탈출 기동(backup->spin->drive)
                      + /scan 최소거리로 트인 쪽부터 시도
                    - 취소 후 완료 대기(레이스 방지)
                    - 퇴화 bearing 가드(근접 시 현재 heading 유지)
                    - localize 가드(TF 없으면 주행 중단)
                    - 도달가능 사전확인(getPath) -> 도달불가 시 사전 스킵
                    - argparse(튜닝값 CLI) + --laps

 nav2_goal_v4.py    v4 = v3 + 좌표계를 맵 파일에서 로드
                    - --map <map.yaml> : origin/resolution/크기 읽어 설정
                    - map origin theta(회전) 반영
                    - check_map_match : Nav2 실제 /map과 불일치 경고
                    - MAP_SIZE_X/Y 비정사각 대응

■ 튜닝 상수 (argparse 옵션으로 실행 시 조절 가능)
----------------------------------------------------------------------
 --timeout       구간 타임아웃(초)            기본 90
 --stuck-time    무진전 스턱 판정(초)          기본 15
 --max-escape    탈출 재시도 횟수              기본 4
 --escape-angle  탈출 회전각(도)              기본 30
 --escape-back   탈출 후진거리(m)             기본 0.2
 --escape-fwd    탈출 전진거리(m)             기본 0.2
 --loop / --laps 반복 / 바퀴수(0=무한)
 --map           (v4만) map.yaml 좌표계 로드

 * 탈출 첫 방향은 /scan 최소거리로 자동 선택(트인 쪽부터), 이후 번갈이
 * 코드 내부 상수(미노출): PROGRESS_EPS=0.05, MAX_RECOVERIES=6,
   MIN_BEARING_DIST=0.05, GRID_MAX=200
 * goto_axis.py 직진 튜닝: DRIVE_HEADING_DEADBAND=8도, GATE=20도


■ 공통 주의
